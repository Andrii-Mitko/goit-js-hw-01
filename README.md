# JavaScript Homework #1

Перші практичні завдання з JavaScript у межах навчання на курсі **Full-Stack
Developer у GoIT**.

## 🔗 Demo

[Переглянути живу сторінку](https://andrii-mitko.github.io/goit-js-hw-01/)

## 📋 Про проєкт

Репозиторій містить три практичні завдання, спрямовані на закріплення основ
JavaScript та розвиток навичок написання функцій.

### Реалізовані завдання

- **Task 1 — Droid Orders:** обчислення загальної вартості замовлення.
- **Task 2 — Product Delivery:** розрахунок вартості доставки та формування
  повідомлення.
- **Task 3 — Element Width:** обчислення ширини HTML-елемента з урахуванням
  відступів і рамки.

## 🛠️ Технології

- HTML5
- JavaScript (ES6+)
- Prettier

## 🚀 Запуск проєкту

1. Відкрий
   [живу сторінку проєкту](https://andrii-mitko.github.io/goit-js-hw-01/).
2. Для перегляду вихідного коду відкрий відповідні файли в папці `js/`.
3. Щоб перевірити результати виконання JavaScript, відкрий інструменти
   розробника браузера та перейди у вкладку Console.
